# KANDAKOV FINAL GITHUB SITE

Финальная редактируемая база сайта для репозитория:
`method-kandakov/method-kandakov-site`

## Архитектура
- Исходники хранятся в GitHub.
- Cloudflare подключается к репозиторию.
- Любой commit создаёт новую публикацию.
- Домен methodkandakov.com переносится только после проверки preview.

## 4 продукта
1. ПКЧ — «Кто я?»
2. СПКЧ — «Как мне действовать?» — 49 900 ₽
3. KANDAKOV PRIVATE — закрытая индивидуальная работа — 490 000 ₽
4. KANDAKOV CLUB — 9 900 ₽/мес или 99 000 ₽/12 мес

Пятый продукт не создаётся.

## Демонстрационные материалы
- `/public/demos/pkch-demo.html`
- `/public/demos/spkch-demo.html`
- `/public/demos/kandakov-private.html`
- `/public/demos/kandakov-club.html`

В PRIVATE выполнены две финальные смысловые правки:
- «ваша роль» → «ваша позиция»
- «Я вырос из прежней роли. Что дальше?» → «Прежний этап завершён. Что дальше?»

ПКЧ, СПКЧ и CLUB не переписывались произвольно: их утверждённая демонстрационная архитектура сохранена.

## Быстрые изменения
`public/config.js` — цены, контакты и будущие ссылки Prodamus.

PRIVATE не получает публичную кнопку оплаты.
Для CLUB предусмотрены отдельные месячная и годовая ссылки.
Цена ПКЧ не выдумана и остаётся незаполненной до отдельного утверждения.

## После одобрения Prodamus
В `public/config.js` вставить:
- `pkch.paymentUrl`
- `spkch.paymentUrl`
- `club.monthPaymentUrl`
- `club.yearPaymentUrl`

## Важный принцип
Решение → Удобство → Впечатление.
Глубина Метода не должна ощущаться как сложность.
