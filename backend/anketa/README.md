# Контрольный путь ПКЧ

Это ограниченный контрольный сценарий одного реального заказа на 10 RUB, а не запуск всех продаж.

- POST /submit?action=payment проверяет подпись Robokassa (пароль #2, алгоритм из кабинета), точный номер контрольного счёта и сумму.
- Адрес получателя задаётся на сервере. Неподписанное поле EMail из уведомления не используется.
- Подтверждение сохраняется в YDB. Письмо содержит HMAC-ссылку, привязанную к номеру заказа, email и фиксированному сроку действия.
- Анкета принимается только по этой ссылке и только после записи подтверждённой оплаты. Повторная отправка возвращает исходный номер анкеты.
- Глобальный SUBMISSIONS_ENABLED не включает общий приём: эта версия принимает исключительно контрольный заказ.
- Последовательный повтор уведомления не отправляет письмо повторно. Сбой между SMTP и записью статуса или параллельные уведомления могут повторить письмо с той же ссылкой (SMTP at-least-once).
- Ответы не включаются в письма, логи или исходный код. Хранение в существующей YDB, срок удаления 180 дней.

## Настройка

Сохранить существующие YDB_ENDPOINT, YDB_DATABASE, YDB_METADATA_CREDENTIALS и Lockbox TOKEN_PEPPER. Создать таблицу schema.sql в существующей базе.

Переменные окружения: CONTROL_ORDER_ID, CONTROL_EMAIL, CONTROL_DEADLINE (UTC epoch milliseconds), ROBOKASSA_HASH (sha256), SMTP_HOST, SMTP_USER, MAIL_FROM.

Секреты из Lockbox: ROBOKASSA_PASSWORD2, SMTP_PASSWORD. Не добавлять секреты, реальные email покупателей, номера заказов и токены в GitHub.

Среда Node.js 22, точка входа handler.handler, таймаут 60 секунд. ZIP содержит handler.js, fulfillment.js, package.json и package-lock.json. Установка зависимостей выполняется при сборке Cloud Functions.

Result URL требует POST. До подключения секретов и положительной проверки обработчика не менять рабочий Result URL и не проводить платёж.

## Проверки

npm ci --ignore-scripts
npm test

Автотесты используют вымышленные данные и заглушки SMTP/YDB. Они не подтверждают реальное получение письма и запись анкеты. Для приёмки отдельно проверить реальную оплату 10 RUB, чек, письмо в почтовом ящике, отправку анкеты и запись в YDB. Пока эти шаги не выполнены, полный путь не считать работающим.
